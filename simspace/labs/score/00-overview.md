# Overview

👋 Welcome to the **Score Labspace**, simulated in your browser!

This is a learning experience for exploring and understanding the CNCF Sandbox project [Score](https://www.cncf.io/projects/score/) and its features.

You will be guided through instructions to run command lines in the terminal on the right, to better understand the concepts of Score and its features. Use the **Run** buttons, or type the commands yourself.

> [!NOTE]
> This is a simulation: every command and its output is scripted, so nothing is installed, nothing runs and the lab behaves the same for everyone. The outputs come from real runs of `score-compose` and `score-k8s`, the ones of `docker`, `kind` and `kubectl` are modelled and abridged. To run the real lab, with VS Code, Docker and a Kubernetes cluster, see [the other ways to run it](https://score-spec.github.io/score-labspace/).

⏱️ Plan for about 30 minutes to complete the whole lab.

✅ Here is how this lab is structured:

- Introduction to Score
- The Score Specification
- Getting started with `score-compose`
- Getting started with `score-k8s`
- Advanced scenario with `score-compose`
- Advanced scenario with `score-k8s`
- Next steps

🎯 By the end of this lab, you will have deployed the **exact same** `score.yaml` file to both Docker Compose and Kubernetes, and you will have customized how it gets deployed without touching the Developer's file.

Let's Score it! 🎶
