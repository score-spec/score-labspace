Score, a CNCF Sandbox project

Score Labspace

Describe a workload once in a score.yaml file, then deploy it to Docker Compose with score-compose and to Kubernetes with score-k8s, and customize how it gets deployed without touching the Developer's file. Pick how you want to run the lab.

    In a Docker Sandbox

    Instructions, VS Code and a private Docker engine (the Kind cluster included) in a single microVM, with sbx. Nothing to clean up on your machine afterwards: sbx rm removes everything the lab created. Then open http://localhost:3030.

    info No AI agent is involved: Docker Sandboxes runs its plain shell sandbox, and you type every command yourself.

    sbx run docker.io/scorespec/score-labsbx:latest -p 3030:3030 -p 8085:8085 -p 8080:8080 --name score-lab -d

    With Docker Compose

    The Labspace on the labspace-infra Compose stack, anywhere Docker/Podman and Docker/Podman Compose are installed. Then open http://localhost:3030.

    docker compose -f oci://scorespec/score-labspace:latest up
